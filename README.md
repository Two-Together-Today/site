# Two Together Today
Static premarital-education site (9 sessions, ~9.5 hours). No build step.
## Deploy
1. Create a GitHub repo, push these files to the root.
2. Settings → Pages → Deploy from branch → `main` / root.
## Edit content
All lessons live in `js/lessons.js`. Each session has segments with `k` (type), `t` (title), `m` (minutes), `h` (HTML).
## Texas fee reduction
Texas Family Code §2.013 requires an 8-hour course from a Twogether in Texas–registered provider; the provider issues the certificate. This site alone does not qualify. Verify current requirements with the Collin County Clerk.
